01

Before you start

Brand Voice and ICP are the same client-level settings the whole suite shares — set them once and every generator, this one included, reads them. A Google Business Profile makes the survey sharper (service-area detection, the map-pack check, auto-fill) but isn't required — pages still generate without one.

Reference page structures are optional but worth setting on the client form — point local landing / service / location / blog post at a real example URL and generated pages mirror how the client actually organizes one.

Frozen clientsCan't generate or reoptimize. Plan Silo's own research step still runs while frozen — it's analysis, not output — only creating the missing pages is blocked.
02

Write a single page

New Page tab: enter a Service (e.g. "emergency plumber") and start typing an Area / Location — you have to pick a suggestion from the autocomplete; a free-typed place that doesn't resolve is rejected, which keeps the geo-targeting honest. For a service-area business with no fixed address, a city field appears — it feeds the optional map-pack rankability check below, not generation itself.

Click Create new page. Generation takes 10–12 minutes — click Leave & finish in the background and it lands in Saved Pages on its own.

Check map pack

An optional button on the same form runs a quick Maps rankability check before you commit to generating — worth using when you're not sure this service + area is realistically winnable in the local pack.

03

The precheck

Before anything generates, the tool checks whether a page for this service + area might already exist — saved in the tool, live on the client's site, or already ranking. Matches are tagged Ranking #N / Generated in tool / On live site (plus a Blog post flag if it looks like an article), each with a Reoptimize this page button.

not a fence, a warning flag

If none of the matches are actually the right page, Write a new page anyway sits at the bottom — the precheck never silently blocks you, it just makes sure you're not about to stake a claim on ground someone already surveyed.

04

Plan a whole silo at once

Plan Silo tab: enter a seed Service + Area / Location and click Plan silo — 4–6 minutes to research the topic, discover related service silos, and check every candidate against what the client already has (that's the plat map above). If the client has no website on file, everything reads "missing" — there's nothing to check against.

Tick the missing parcels you want (or Select all missing), then Create N selected page(s) — each one runs the same full generation as a single page, as background jobs, with a live counter ("3 / 8 done") and failures called out separately for retry.

05

Score & reoptimize

Score tab

Checks a page's composite score and brand-voice scorecard without rewriting anything — a quick "is this actually a problem" read before committing to a rewrite pass.

Reoptimize tab

A multi-line box — one URL per line handles a single page too — where a bulk line can be URL | keyword | area to pin the target for that specific page. A page gets rewritten when it's below 75/100 on SEO, or fails its brand-voice bar — a page clearing both is skipped with a note. Unlike Blog/Ecommerce reoptimize, there's no notes field here — you can't steer a specific rewrite beyond what the scorer's own deficiencies drive.

Destinations: Save in the app (always) and optionally publish to Google Doc. GitHub and WordPress exist for this tool but are marked "Coming soon" for reoptimize specifically.

06

Saved Pages & Drafts

Saved Pages lists everything generated or reoptimized, with a composite score and a Generated/Reoptimized badge. Deleting there is a soft delete — it moves to Drafts, where you can Restore it or delete it permanently; Empty drafts clears the whole bin at once.

07

Publishing

Publish to Google Doc and Publish to WordPress (Draft or Publish) live on a page's detail view; GitHub publishing lives on the bulk publisher on Saved Pages instead. A generated page's detail view also carries a GBP Posts tab (AI-suggested posts + the full composer) alongside Related Pages.

If publish is blocked by the client's voice card, check the panel below, fix the wording, or click Publish anyway to override deliberately. Regulated clients carry a separate, non-overridable compliance gate.

08

The brand-voice card

Every generated page (for a client with a guide on file) carries a headline verdict plus a 0–100 score:

Sounds like this client Drifting from the guide

Eight scored dimensions follow, worst first — a dimension below 80 shows a real quoted excerpt proving where it drifted; a passing one shows no quote. No guide on file → no panel at all, deliberately, so a missing panel is never mistaken for "checked and passed." A guide that exists but couldn't be scored shows a distinct "Brand voice not checked" warning instead.

Troubleshooting

The precheck found the wrong pageUse "Write a new page anyway" — it never forces a match.
A city got rejectedPick from the autocomplete; a free-typed location that doesn't resolve isn't accepted.
Everything shows "missing"Check the client has a website on file — without one there's nothing to check existing pages against.
Reoptimize skipped a pageIt only rewrites a page failing SEO (75/100) or its voice bar — clearing both is a deliberate skip, and there's no notes field to force it here.
No brand-voice panelThe client has no guide on file — set one and it appears on the next generate or reoptimize.
11

Practice exercises

  • Write a single page and watch the precheck run before it commits to generating.
  • Run Plan Silo on a client with a website on file and read the found/on-site/missing split.
  • Bulk-create two missing pages and watch the live counter.
  • Score a live URL, then Reoptimize it and compare the before/after.
  • Soft-delete a page, then restore it from Drafts.
