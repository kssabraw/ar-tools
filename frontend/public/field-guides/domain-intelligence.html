01

Before you start

Any logged-in user can open a file, but every action spends from a shared daily budget (200 calls/day, agency-wide) — the page header always shows "Budget left today: N calls," red at zero.

Standalone (sidebar entry) gives Domain lookup only. Opened from a client workspace, Keyword gap and Discover unlock too, since those need the client's registered competitors in Competitive Intel.

02

Domain lookup

Type a domain, pick a role — Competitor / Prospect / Own site — and click Analyze. Auto-prefills the client's own hostname on first load. Once a snapshot exists: Overview (traffic, keywords, DR, RD, traffic value, content-mix bar), Ranked Keywords (keyword/position/volume/CPC/KD/ intent/value), Pages (grouped by ranking URL). Each has its own Export CSV.

03

Keyword gap

"Keywords your registered competitors rank for that {client} doesn't — or ranks poorly for." Run gap analysis tags each row missing or weak, with an opportunity score. No competitors registered? A note points you at Competitive Intel first.

04

Discover

"Domains that share the most search results with {client}." Find competitors (one paid call) lists domain/shared keywords/avg position/organic keywords, each with an Add button that registers it in Competitive Intel — already-registered domains show green "Registered" instead.

05

Snapshots & budget

the file doesn't re-open itself for free, but close does

A snapshot caches for 24 hours — re-analyzing the same domain inside that window is free and silently re-serves the stored snapshot. There's no "force refresh" button in this version of the UI.

The Backlink Gap analysis is built on the backend but has no button in this version of the frontend — Domain lookup, Keyword gap, and Discover are the three live modes today.
