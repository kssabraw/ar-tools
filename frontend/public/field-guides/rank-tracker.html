01

Before you start

This tracks Google organic (blue-link) positions — never Maps/local-pack, that's the separate Maps Ranker. It works with or without Search Console connected, but it's a materially different tool either way.

With GSCOverview, Pages, and Brand search tabs unlock; real click/impression numbers throughout; green "Search Console" pill.
Without GSCThose three tabs are hidden; you land on Keywords by default; rank comes from a weekly DataForSEO live check; blue "DataForSEO" pill.

Not freeze-gated — the tracker keeps working during a client freeze; a freeze pauses output, not observation.

02

Track keywords

Track keywords — one per line or comma-separated. Import CSV reads the first column. Refresh live ranks enqueues a background DataForSEO pull for keywords GSC doesn't cover. After adding your first keywords, a banner offers to Run rankability right away.

03

Read the Overview

(GSC-connected clients only.) A plain-English headline + narrative, KPI cards, status chips (Climbing / Stable / Volatile / Dropping / At risk / Not in top 100 / No data), Striking distance (untracked page-2 opportunities, one-click Track), and Needs attention — the top 8 keywords sorted by urgency.

04

Work a keyword row

Click a row to expand: a position chart, point-in-time ranks, and a landing-page breakdown with a Pin button if the keyword ranks on more than one page. Icon buttons: camera (SERP Snapshot — the AI Overview, top-10, per-domain authority), bar chart (Organic Rank Analysis report — needs a snapshot first), gauge (Authority report DR/UR/RD), trash (stop tracking). A deindex-risk keyword shows a colored banner with a Check index button.

05

Rankability & SERP Trends

Rankability — a 0–100 winnability score per keyword, sorted by Quick wins (default), Rankability, or Potential value; a keyword already top-3 is deliberately excluded — no upside left to capture. SERP Trends — signal/enhancement prevalence over time, a "what changed since last capture" digest, and a scrubbable per-keyword timeline.

06

Alerts

four bells, not one

A 6+ spot weekly drop from top-15, falling off page 1, a 6+ spot 30-day drop from ~top 20, or a gradual multi-week slide — plus deindexing. Each clears automatically once the keyword recovers.

Mark all read clears the unread badge; individual rows get Read or Dismiss.

07

Reports

(GSC-connected only.) Schedule: As needed / Weekly / Monthly / Every N days, plus an optional Google Doc delivery. Generate now for an on-demand report.

Every open drop, quick win, and hidden win surfaces automatically on the client's Action Plan — you don't have to go looking for it separately.

08

Troubleshooting

Overview/Pages/Brand search missingNo verified GSC property — the tool runs DataForSEO-only.
A snapshot/report says "still processing"Real background jobs — the page stops polling after a few minutes but the job keeps running.
A #1 keyword isn't a "quick win"Deliberate — nothing left to capture.
