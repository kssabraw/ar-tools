01

Before you start

Tracks whether a brand gets mentioned when six AI assistants — ChatGPT, Claude, Gemini, Perplexity, Google AI Overview, Google AI Mode — answer the client's tracked keywords. Not a rank position; visibility is the share of scanned answers that mention the brand, weighted by classifier confidence.

You need at least one active keyword to scan. Competitors are optional and free to include — re-classified from the same answers, no extra scan.

02

Run a scan

Run scan opens a dialog: per-engine checkboxes (all six preselected — no cost reason to narrow), Include competitors, and a live summary ("N keywords × M engines = T answers scanned"). Close the dialog and it keeps running; reopening the page reconnects automatically.

03

Read the Overview

A Global Health Score arc gauge (≥70 "Healthy," ≥40 "Partial," below "Invisible"), Visibility Share, Keywords Tracked, Engines Monitored. The mention matrix — one row per keyword, one column per engine — reads: ✓ found, ✗ not found, "!" scan failed, a pulsing dot pending, or a slashed circle (Google generated no AI answer at all for that search — excluded from the score, not a miss).

04

Diagnose a silence

Click a red ✗ cell to open the detail sheet: mention type, sentiment, confidence, a possible-misinformation flag, and a "Why invisible" section with an AI-generated diagnosis.

the diagnosis can go quiet too

It's a separate, best-effort call that can independently fail — and it deliberately won't auto-retry, so a failure doesn't silently burn another paid call.

05

Keywords & Competitors

Suggest AI queries (grounded on the client's profile) or Import from rank tracker to pull in existing keywords. Competitors add by name and cost nothing extra — they ride the same scanned answers.

which source of keywords

Import from rank tracker when the client already has a tracked keyword set you trust — it's the fastest way to get AI-visibility coverage on the same terms you're already measuring in organic. Reach for Suggest AI queries when you're starting fresh on this client, or when the way people actually ask an AI assistant differs from how they'd type a Google search — a question-form phrasing a search-keyword list wouldn't surface.

06

Reports

Google Doc — a per-engine + matrix + narrative report to the client's Drive folder. Export report — a white-label HTML report over a date range, with Preview/Download/Print. Export CSV — the full raw scan history.

which report

Google Doc suits an internal or narrative-style deliverable — it lands in Drive with the rest of the client's documents. Export report is the client-facing option — a date-range, printable/downloadable page built specifically to hand to (or present for) the client, with client-friendly framing throughout. Export CSV is for when someone needs the raw numbers — your own analysis, a spreadsheet the client's team wants to slice themselves — not a finished deliverable.

07

Schedule

Off / Weekly / Monthly, a day + hour (UTC), and an Include-competitors checkbox.

Which cadence. Weekly suits a client actively working on AI visibility, or a competitive niche where answers can shift quickly. Monthly is the steady default for most retainers — enough to catch a real trend without over-scanning keywords that don't move often. Off is for a client you're not actively tracking this for yet — use the manual Run scan button on demand instead.

The comparison card always shows the newest scan that did include competitors — a brand-only scan in between doesn't blank it.
