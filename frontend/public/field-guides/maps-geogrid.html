01

Before you start

This tracks Google Maps / local-pack rank across a grid of simulated searches around the business — never the organic blue-link SERP, which is the separate Organic Rank Tracker.

Setup needs, at minimum, a Place ID and center lat/lng before any scan can run — the Setup tab warns explicitly if it's missing. Weekly scanning with zero active keywords also silently skips that client, flagged the same way. A geo-grid bills per keyword × pin — scan a subset when you just want to spot-check.

02

Run a scan

Run scan now (Heatmap or One-offs) — the button shows a count when you've picked a subset. A Stop scan button appears mid-run; a Weekly: On/Off toggle flips scheduling without opening Setup.

Heatmap vs. One-offs — which button. Run from Heatmap when this is the client's regular check-in and you want it counted — most of the time, the weekly scheduled scan already covers this, so a manual Heatmap run is for when you need a fresh read now, not on the weekly clock, and still want it on the record. Run from One-offs for a spot-check you deliberately don't want polluting the client's trend line — testing a hypothesis, checking right after a fix before the next scheduled scan, or scanning a keyword you're not sure is worth tracking yet.

Turning Weekly off. Worth doing for a client that's paused, being decommissioned, or where the retainer no longer covers ongoing Maps tracking — it stops the recurring spend without losing scan history. Leave it on for anything actively worked.

03

Read the Heatmap

A completed scan gives, per keyword: At a glance (average rank, top-3/top-10 coverage, found pins, strongest/weakest directions, top competitor), the grid map itself, and an expandable full numeric grid. A legend maps rank bands to color (1–3 / 4–7 / 8–10 / 11–15 / 16–20 / not ranked).

a one-off carries its own flag

A manual scan shows an indigo "One-off · not in reporting" pill — never mistaken for the client's scheduled record.

04

One-offs

Manual spot-checks — excluded from trends, client reports, and alerts on purpose, and they don't auto-generate a report (use Generate report on the row if you want one anyway). Use the keyword-scope picker to keep cost down.

05

What changed

Compares two scans: performance over time, coverage by area, alerts (Mark all read / Read / Dismiss), and a week-over-week picker. A radius change between the two compared scans is auto-normalized to the shared area, flagged with a banner — deliberate, not a bug.

06

History

Scheduled scans only — the client's real record. Trend chart, Share of Local Voice, local relevance scorecard, competitor momentum/intelligence, review analytics, backlink authority, GBP profile audit. Trash icon deletes a scan (blocked in-flight); Clear all is scoped per tab.

07

The Local Rank Analysis report

Auto-generated after every scheduled scan (one-offs skip this — no LLM spend for a scan outside the client's record). Contents: ring/octant analytics, a narrative, a saved map image, weak coverage areas named to real nearby cities, and suggested hyper-local page targets with Google Maps deep links.

View it via the accordion on a keyword's Heatmap card, or Printable report on History (browser print → Save as PDF). If a Drive folder is configured, it also auto-publishes as a Google Doc.
